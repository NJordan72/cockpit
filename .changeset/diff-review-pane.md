Diff review pane: open a `review` pane from a Tasks row's right-click menu, the Activity panel's Git or Files tabs, or the toolbar (**± Diff** / `Cmd+Shift+G`). It shows the branch's changes since its merge-base with the remote's default branch plus uncommitted and untracked files, collapses large or binary files, lets you click lines (or Shift+click a range) to collect draft comments, and sends all comments to the task's agent (or a chosen agent pane) as one prompt — waiting until idle if the agent is working, and refreshing as files change.
