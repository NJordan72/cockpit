Terminal search and Activity log filtering: press Cmd+F (configurable as `findInPane`) to open a floating find bar in any terminal pane with Enter/Cmd+G for next match, Shift+Enter/Cmd+Shift+G for previous match, Esc to close, case-sensitive and regex toggles, and a live match counter. The Activity panel's Log tab now includes a compact text filter alongside the Events and Tools chips to filter entries by tool name, command, file path, or text.
