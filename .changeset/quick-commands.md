Quick commands: list prompts you run often in `quickCommands` in `config.json`, each with the preset, model, and effort to run it with, and an optional input such as a Slack link. Cmd+Shift+J (or **⚡ Quick** in the toolbar) runs one. By default it runs in the background, in a tab the tab bar leaves out: the Sessions panel lists it under Background, and macOS notifies you when it needs input or finishes, even while Cockpit is focused. Click it to open it as a tab, or dismiss it with ×.
